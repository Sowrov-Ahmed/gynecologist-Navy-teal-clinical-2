# Dr. Rukhsana Alam: Gynecologist Portfolio ("Clinical Editorial" design)

Static multi-page site: HTML + Tailwind CSS (CDN) + vanilla JS. No build step.

## Folder map
```
/                      <- the 15 pages live here (each member adds theirs)
assets/js/             <- SHARED KIT (do not edit): tailwind-config, data, ui, art, layout
assets/js/pages/       <- page scripts (one file per page, added by members)
assets/images/         <- five doctor photos (WebP, optimized from the supplied PNGs) + favicon
docs/                  <- PART-1 ... PART-5 documentation (added by members)
_qa/check.html         <- merge checker (delete before delivery)
prompts/               <- the five member prompts (delete before delivery)
```

## Run locally
Open the folder in VS Code and use Live Server, or run `npx serve .`.

## Edit content in one place
Doctor details, chambers, services, posts, testimonials, FAQs and photo metadata all come from `assets/js/data.js`.
